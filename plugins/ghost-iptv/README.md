# 👻 Ghost IPTV & Addons (Alazterflix TV)

Plugin oficial do **Ghost IPTV** integrado ao **Alazterflix** e ao **Ghost Games Launcher**.

Porta as funcionalidades completas do projeto [alazter/ghost-iptv](https://github.com/alazter/ghost-iptv) para PC, com:
* Suporte nativo a canais de TV ao vivo e listas M3U/M3U8.
* Conversor universal de Addons de TV do Stremio para reprodução instantânea.
* Programação EPG perpétua autônoma com mini-guia e informações em tempo real.
* InfoBar translúcido elegante com efeito marquee nos títulos.
* Sistema de atualização contínua e sincronização direta com o repositório oficial no GitHub (`alazter/ghost-iptv`).
