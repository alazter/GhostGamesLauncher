# 🎨 Cyber Neon Layout & Customizer Plugin

Plugin oficial de personalização visual e layout para o Ghost Games Launcher.

## O que ele faz:
- Remodela o formato e bordas dos botões com cantos arredondados e brilho neon.
- Melhora a elevação, sombras e escala das capas no grid da Biblioteca ao passar o mouse.
- Injeta regras de CSS de forma atômica e 100% segura através do GhostShield.
